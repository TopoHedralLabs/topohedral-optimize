Struct QuadraticModel 

Source 
pub struct QuadraticModel { /* private fields */ }
Expand description

Quadratic model maintained by quasi-Newton optimizers.

The model keeps its direct and inverse Hessian approximations internally consistent. Read-only accessors expose the current state without allowing callers to replace one component independently of the others.
