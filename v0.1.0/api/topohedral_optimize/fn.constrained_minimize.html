) -> Result<VectorReturns, ConstrainedError>
Expand description

Minimizes a function subject to optional bounds and vector constraints.

Equality constraints are interpreted as h(x) = 0; inequality constraints are interpreted as g(x) <= 0.

§Errors

Returns ConstrainedError if method options or dimensions are invalid, bounds are paired with an incompatible inner solver, an inner solve fails, or the iteration limit is reached.
